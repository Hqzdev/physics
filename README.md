# Физический движок воды

Трёхмерная динамика частиц на C++17 с проекцией в окно Windows. Силы вычисляются из потенциальной энергии, затем интегратор обновляет скорости и координаты. Температура, давление и локальная структура измеряются во время расчёта. Цвет помогает увидеть разные окружения частиц в одной ячейке.

Реализованы две физические модели: гибкие молекулы H₂O с электростатикой Эвальда и заранее полностью ионизированная смесь H⁺/O⁸⁺ в электронном фоне. У электронов рассчитывается распределение Ферми — Дирака, включая давление вырождения. Это небольшой исследовательский движок с явными приближениями; его фазовые границы пока не откалиброваны по экспериментам.

## Запуск в Windows

Нужна Visual Studio с компонентом **«Разработка классических приложений на C++»**. Откройте `built.bat`: он найдёт установленный MSVC через `vswhere`, соберёт программу и запустит `build\win\sim.exe`. При запуске из Developer Command Prompt используется уже настроенный компилятор. Кодировка консоли переключается на UTF-8.

Для сборки через CMake:

```powershell
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
.\build\Release\sim.exe
```

Последний путь соответствует генератору Visual Studio. При другом генераторе исполняемые файлы могут находиться непосредственно в `build`.

## Начальные эксперименты

Клавиши `1`–`7` создают новую систему. Меняются исходные координаты, плотность, температура и выбранная физическая модель. После старта начальная метка не удерживает частицы в определённом состоянии.

| Клавиша | Начальная конфигурация | T | Плотность, кг/м³ |
| --- | --- | ---: | ---: |
| `1` | 64 молекулы, плотная конфигурация с разными ориентациями | 300 K | 997 |
| `2` | 64 молекулы, кислородная сетка кубического льда Ic и водороды по ледовым правилам | 180 K | 920 |
| `3` | 64 разреженные молекулы | 500 K | 3 |
| `4` | Плотный слой из 32 молекул и 8 молекул в разреженной области | 400 K | 623,125 |
| `5` | 64 молекулы горячего флюида | 800 K | 300 |
| `6` | 21 ядро O⁸⁺ и 42 ядра H⁺, горячий электронный фон | 20 млн K | 1000 |
| `7` | Та же ионная смесь при большой плотности, вырожденный электронный фон | 1 млн K | 1 млн |

Конфигурации требуют релаксации. Затравка льда не доказывает его термодинамическую устойчивость, а начальный слой с газом не гарантирует равновесное сосуществование фаз.

## Управление

| Клавиша | Действие |
| --- | --- |
| `↑` / `↓` | Увеличить / уменьшить целевую температуру в 1,1 раза |
| `←` / `→` | Расширить / сжать ячейку примерно на 3% по объёму |
| `B` | Включить / выключить баростат Монте-Карло |
| `←` / `→` при включённом `B` | Уменьшить / увеличить целевое давление баростата |
| `T` | Включить / выключить тепловую баню; её выключение также выключает баростат |
| `Space` | Пауза |
| `Home` | Заново создать текущий эксперимент |
| `+` / `−` | Число шагов физики за кадр: от 1 до 128 |
| `Esc` | Закрыть окно |

По умолчанию объём фиксирован, тепловая баня включена. Давление вычисляется, поэтому оно может существенно отличаться от атмосферного. В маленькой системе мгновенные значения сильно колеблются; рядом показано среднее с временным масштабом 100 фс.

В плазменной модели температура электронного фона равна выбранной целевой температуре и сохраняется при выключении ионной бани. При фиксированном объёме и неизменной температуре электронов движение ионов становится консервативным.

## Цвета

| Цвет | Что означает |
| --- | --- |
| Голубой | Льдоподобное кристаллическое и малоподвижное окружение |
| Синий | Плотное жидкоподобное окружение |
| Жёлтый | Мало соседей: газоподобное окружение |
| Зелёный | Промежуточное окружение / возможная граница плотной области |
| Оранжевый | Некристаллический плотный флюид при измеренных T/P выше справочных критических значений воды |
| Фиолетовый | Ионная смесь с преимущественно невырожденными электронами |
| Красно-розовый | Ионная смесь с вырожденным электронным фоном, Tₑ/Tꜰ < 1 |
| Серый | Наблюдений пока недостаточно |

Метки у молекул локальные: одновременно могут быть видны несколько цветов. Атомы H светлее и меньше атомов O. Окраска не меняет силы. Оранжевый цвет не устанавливает критическую точку используемой модели, а зелёный не является доказательством фазового равновесия.

## Какие состояния охвачены

| Режим | Возможности реализации |
| --- | --- |
| Лёд, жидкость, пар | Молекулярная динамика и структурные признаки; затравка только Ic, остальные полиморфы не подготовлены |
| Жидкость + пар | Неоднородная начальная конфигурация и локальные цвета; равновесная линия насыщения не вычисляется |
| Сверхкритическая вода | Можно исследовать горячий молекулярный флюид; реальная критическая точка служит справочным ориентиром |
| Суперионная вода | Не реализована: нужен проверенный реактивный или обученный на квантовых расчётах потенциал |
| Плазма | Движущиеся полностью ионизированные ионы и электронный фон; путь распада H₂O и ионизация не рассчитываются |
| Ферми-вырожденное вещество | Учтено вырождение идеального электронного фона; это не отдельная молекулярная фаза воды |
| БЭК | Не реализован; квантовый бозе-газ требует другого представления состояния и не считается здесь фазой обычной воды |
| Тройная и критическая точки | Это условия равновесия, а не дополнительные виды частиц; поиск этих точек не реализован |

## Расчёт без окна

На Linux и macOS собираются ядро, консольный запуск и проверки. Графическое окно использует Win32.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
./build/physics_headless 6 10000
```

Аргументы `physics_headless`: номер эксперимента `1..7` и число шагов. Вывод — одна строка CSV с временем, T, P, плотностью, энергиями и Tₑ/Tꜰ. Физическое время вычисляется из шагов интегратора и не равно времени работы компьютера.

Проверки включают производные энергии, закон сохранения импульса, энергию изолированной молекулы, постоянную Маделунга для Эвальда, тепловую баню, пределы электронного EOS и статистику баростата. Файл `.github/workflows/build.yml` подготавливает сборку на Windows и Linux после публикации изменений.
