# Как работает физика

## Что создаёт движение

Потенциал задаёт энергию U координат всех частиц. Сила на частицу — отрицательная производная этой энергии: Fᵢ = −∂U/∂rᵢ. Интегратор применяет mᵢ·dvᵢ/dt = Fᵢ и drᵢ/dt = vᵢ. Расположение частиц изменяет силы на следующем шаге.

Ни одна метка `LocalState` не входит в уравнения движения. Условия в анализаторе выбирают подпись и цвет уже полученного результата. Смена эксперимента — создание новой системы с другими начальными условиями и, для плазмы, другой физической моделью. Нагрев обычной молекулярной модели автоматически не переводит её в плазменную.

## Единицы

| Величина | Внутренняя единица |
| --- | --- |
| Координаты | Å = 10⁻¹⁰ м |
| Время | фс = 10⁻¹⁵ с |
| Масса | а.е.м. |
| Заряд | элементарный заряд e |
| Энергия | кДж/моль |
| Сила | кДж/(моль·Å) |
| Скорость | Å/фс |
| Давление в отчёте | МПа |

Коэффициент перевода F/m в Å/фс² равен 10⁻⁴. Кинетическая энергия частицы в этих единицах: K = 5000·m·v². Суммы энергий относятся к моделируемой ячейке с молярной нормировкой каждого её слагаемого; это не энергия на один моль всей воды в ячейке. Для энергии одной физической ячейки в джоулях делите число кДж/моль на Nₐ/1000.

## Молекулярная вода

Каждая молекула содержит O и два H. Топология постоянна. Энергия:

```text
U = Σсвязей ½ kb (r - r0)²
  + Σуглов ½ kθ (θ - θ0)²
  + Σпар O-O U_LJ(r)
  + U_Ewald(заряды, координаты, ячейка)

U_LJ(r) = 4 ε [(σ/r)^12 - (σ/r)^6]
```

| Параметр | Значение |
| --- | ---: |
| Масса O / H | 15,9994 / 1,008 а.е.м. |
| Заряд O / H | −0,82 / +0,41 e |
| r₀ | 1,012 Å |
| θ₀ | 113,24° |
| kᵦ | 4431,13 кДж/(моль·Å²) |
| kθ | 317,57 кДж/(моль·рад²) |
| σ | 3,16549 Å |
| ε | 0,6502 кДж/моль |

Это реализация на параметрах типа SPC/Fw с собственной обработкой отсечения LJ. Для O–O используется r꜀ = min(9 Å, 0,49 L). Из потенциала вычитается значение на r꜀ и добавляется линейная поправка, чтобы энергия и сила обращались в ноль на отсечении. Поправки на дальний хвост дисперсии не добавлены. Поэтому результаты нельзя автоматически считать воспроизведением всех опубликованных характеристик SPC/Fw.

Водородные связи не задаются отдельными пружинами между молекулами: предпочтительные взаимные ориентации возникают из зарядов и геометрии. Пружины O–H описывают химические связи внутри молекулы.

## Электростатика Эвальда

Прямое кулоновское взаимодействие медленно убывает с расстоянием. Суммирование Эвальда учитывает периодические копии нейтральной ячейки:

```text
U_real = C Σi<j qi qj erfc(α rij) / rij
U_k    = (2π C/V) Σk≠0 exp[-k²/(4α²)] |Σj qj exp(i k·rj)|² / k²
U_self = -C α/√π Σi qi²
```

Из суммы удаляется прямое кулоновское взаимодействие трёх пар внутри одной молекулы, потому что внутримолекулярную энергию здесь описывают связи и угол. Периодические образы молекулы остаются. Внешние граничные условия проводящие; поверхностная дипольная поправка равна нулю.

По умолчанию αL = 6, радиус реального суммирования 0,49L, обратные волны ограничены сферой |n| ≤ 6. Это конечная численная точность. Проверка постоянной Маделунга NaCl подтверждает энергию с относительным допуском 10⁻⁴ для своего эталона; она не заменяет исследование сходимости на каждой конфигурации воды.

## Интегратор и тепловая баня

BAOAB состоит из пяти частей:

1. Половина изменения скорости под действием текущей силы.
2. Половина перемещения с полученной скоростью.
3. Обмен импульсом с баней.
4. Вторая половина перемещения, затем пересчёт силы.
5. Вторая половина изменения скорости.

В третьей части решается процесс Орнштейна — Уленбека:

```text
v_new = c v_old + sqrt[(1-c²) kB T / m] R
c = exp(-dt / τ),  τ = 100 фс
```

R — независимые нормальные случайные числа. Преобразования единиц присутствуют в коде. Шум и торможение связаны одной температурой, что обеспечивает флуктуационно-диссипативное соотношение. Общий дрейф удаляется; температура вычисляется по 3N−3 степеням свободы. Выключение бани сводит схему к velocity Verlet.

Максимальный шаг — 0,2 фс для молекул и 0,02 фс для ионов. Он дополнительно ограничивается минимальным межатомным расстоянием, максимальной скоростью и ускорением. Это практическая защита от слишком большого шага, не строгая оценка ошибки. Переменный шаг в общем случае нарушает точную симплектичность; для численного исследования необходимо проверять сходимость по dt.

## Температура и давление

T = 2K / [(3N−3)kB]. Внутримолекулярные колебания классические и участвуют в этой температуре. При низких температурах такое распределение энергии физически неточно: квантовые колебания ядер отсутствуют.

Давление вычисляется через виртуальное изменение объёма:

```text
P = [2 K_перенос / 3 + kB T] / V - dF_конфигурации/dV
```

Для молекул меняются положения центров масс, их внутренняя геометрия сохраняется. K_перенос — энергия поступательного движения молекул. Для ионов каждый ион является отдельной группой. Дополнительный kBT/V возвращает вклад общего импульса, удалённого в конечной системе. Производная берётся симметрично по log(V) с приращением 10⁻⁴; у плазмы учитываются также электронная свободная энергия и зависимость экранирования от плотности.

Это давление реализованного эффективного гамильтониана. Для плазмы оно не является проверенным полным уравнением состояния реальной H/O-смеси: некоторые объёмные поляризационные и корреляционные вклады не включены.

## Баростат

Каждые 32 шага при включённом баростате предлагается log(V′/V) из равномерного интервала [−0,02; 0,02]. Вероятность принятия:

```text
min(1, exp[-(F′ - F + P_target (V′ - V))/(kB T)
           + (N_groups + 1) log(V′/V)])
```

Множитель N_groups описывает энтропию переноса групп; дополнительная единица возникает из предложения, симметричного в log(V). При фиксированной химической модели это выборка из соответствующего изотермо-изобарического ансамбля. Баростат не является моделью реального поршня и меняет траектории переноса. Для измерения динамических свойств после релаксации его следует выключать. Проверка на идеальном газе сравнивает средний объём с (N+1)kBT/P.

## Ионы и электронный фон

Состав задан как H⁺ и O⁸⁺ в отношении 2:1. Число электронов Nₑ равно суммарному положительному заряду, поэтому фон нейтрализует ячейку. Ионизация не вычисляется: выбор полного заряда является исходным допущением, особенно существенным при охлаждении и сжатии.

Электроны считаются идеальным нерелятивистским ферми-газом:

```text
f(p) = 1 / [exp((p²/(2me) - μ)/(kB Te)) + 1]
n = 2/(2πℏ)³ ∫ f(p) d³p
Pe = 2/3 · 2/(2πℏ)³ ∫ [p²/(2me)] f(p) d³p
Fe = μ Ne - Pe V
EF = ℏ² (3π²n)^(2/3) / (2me)
TF = EF/kB,   theta = Te/TF
```

При промежуточных температурах μ находится бисекцией, интегралы считаются методом Симпсона. При theta < 0,05 используется разложение Зоммерфельда до theta⁴; при theta > 10⁴ — классический предел. В точке theta = 1 формулы не переключаются: меняются только подпись и цвет. При T = 0 давление равно 2nEF/5 и остаётся ненулевым.

Из отклика электронов получается экранирование:

```text
kappa² = e²/epsilon0 · (dn/dmu)_Te
lambda = 1/kappa
Uij = C Zi Zj exp(-rij/lambda) / rij
```

Ионный потенциал Юкавы сдвигается по энергии и силе на r꜀ = 0,49L. Ионы двигаются по его градиенту. Электронная температура постоянна и равна выбранной пользователем; электрон-ионный теплообмен явно не моделируется.

Модель приближает статическое линейное экранирование. Не включены обмен и корреляция электронов, динамическое экранирование, изменение зарядовых состояний, нейтральные частицы, фотоны, квантовая динамика ионов и релятивистские эффекты. При длине экранирования, сравнимой с L, отсечение существенно искажает дальние взаимодействия. Числа в диапазоне допустимых настроек сами по себе не доказывают применимость всех этих допущений.

## Как определяется цвет

Для каждого O находятся соседи ближе 3,5 Å. Тетраэдрический параметр q рассматривает углы между четырьмя ближайшими направлениями: q = 1 для идеального тетраэдра. Самого q недостаточно для обнаружения кристалла.

Дополнительно сравниваются локальные ориентационные окружения q6 через полином Лежандра P₆. Льдоподобная метка требует не менее трёх согласованных соседей, корреляции > 0,65, q > 0,75, 3–5 соседей и малого перемещения O: менее 0,12 Å² за доступное окно не короче 100 фс. До накопления такого окна кристаллическое окружение отмечается серым. Обычно окно составляет около 200 фс. Для редкого измерения оно может быть длиннее; фактическая длина возвращается в отчёте.

0–1 сосед даёт газоподобную метку; два соседа — промежуточную; более плотное окружение без кристаллических признаков — жидкоподобную. Для устойчивости отображения смена уже определённой метки требует пяти повторений; первая определённая метка появляется сразу. Это настраиваемые эвристики анализа, не экспериментально подтверждённый фазовый классификатор и не идентификация всех полиморфов льда.

Смешанная глобальная подпись означает наличие плотных и разреженных окружений. Она не устанавливает равенство химических потенциалов фаз. Горячий флюид выделяется по средним измеренным T/P относительно справочных 647,096 K и 22,064 МПа; критическая точка именно этого потенциала отдельно не найдена.

## Пределы охвата

Тройная точка означает равновесие трёх фаз, критическая — конец линии сосуществования жидкости и пара. Для их нахождения нужны расчёты свободной энергии, размера системы и сходимости, которых здесь пока нет.

Высокобарические льды и суперионная вода требуют подходящего потенциала и стартовых структур. В суперионном режиме нужно независимо показать устойчивость кислородной решётки и диффузию водорода. Фиксированные молекулы SPC/Fw не дают водороду менять химических соседей, поэтому этот режим ими не реализован.

Бозе-эйнштейновский конденсат не объявляется ещё одной фазой обычной воды. Для квантового бозе-газа нужно моделировать квантовое состояние, а не только классические координаты. Ферми-вырождение здесь учтено именно для электронов уже ионизированного вещества.
